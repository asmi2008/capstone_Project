# Asmi Mart - Online Fashion Shopping System

## Project Overview
Asmi Mart is an online fashion shopping system that allows users to browse products, manage their cart, place orders, and track order history.

## Technologies Used
- Java
- Maven
- Apache Tomcat
- SQL Server
- HTML
- CSS
- JavaScript

## Main Modules
- User Registration and Login
- Product Management
- Shopping Cart
- Checkout
- Order Management
- Admin Management
- Seller Management

## Project Status
The project is developed and tested locally using Apache Tomcat and SQL Server.
